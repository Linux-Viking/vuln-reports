CVE-2021-44228

Apache Log4j2 JNDI lookups reach attacker controlled LDAP endpoints

CISA KEV Active Exploitation
EPSS: 0.944570000
Threat Vector: NETWORK
Complexity: LOW
Description
Apache Log4j2 2.0-beta9 through 2.15.0 JNDI features used in configuration, log messages, and parameters do not protect against attacker controlled LDAP endpoints. An attacker who controls log messages can execute arbitrary code.
Affected Products
  • Apache Log4j2 (2.0-beta9 to <2.3.1, 2.4 to <2.12.2, 2.13.0 to <2.15.0)
Affected Hosts
erp01.example.test (192.0.2.40) (443/tcp)

🛡️ Remediation Recommendation

Upgrade to Log4j 2.17.1 or later; remove the JndiLookup class as an interim mitigation.

OpenSSL: Obtain sensitive information from process memory via crafted packets that trigger a buffer over-read

CISA KEV Active Exploitation

Complexity: LOW
