CVE ID: CVE-2021-44228
Title: Apache Log4j2 JNDI lookups reach attacker controlled LDAP endpoints
Description: Apache Log4j2 2.0-beta9 through 2.15.0 JNDI features used in configuration, log messages, and parameters do not protect against attacker controlled LDAP endpoints. An attacker who controls log messages can execute arbitrary code.
CVSS: 10.0 | KEV: Yes | EPSS: 0.944570000
Exploitability: Exploited in the wild | PoC: https://www.exploit-db.com/exploits/00000
Threat Vector: NETWORK | User Interaction: NONE | Complexity: LOW
Affected: Apache Log4j2 (2.0-beta9 to <2.3.1, 2.4 to <2.12.2, 2.13.0 to <2.15.0)
References: https://nvd.nist.gov/vuln/detail/CVE-2021-44228, https://www.cve.org/CVERecord?id=CVE-2021-44228, https://logging.apache.org/log4j/2.x/security.html, https://www.exploit-db.com/exploits/00000, https://example.test/advisory/log4j
